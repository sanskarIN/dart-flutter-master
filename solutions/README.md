# Solutions

Educational solution references belong here when publishing them publicly is appropriate.

A solution should explain the reasoning and trade-offs, not only provide a final code dump. Where multiple valid approaches exist, note the alternatives and why the reference implementation chose one.

Solutions must not contain production credentials, private endpoints, copyrighted third-party code, or unrelated paid-book prose.
