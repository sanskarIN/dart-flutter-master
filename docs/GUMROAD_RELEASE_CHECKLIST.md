# Gumroad Release Checklist

Use this before updating or publishing a **Dart & Flutter Full Mastery** product on the official Gumroad storefront.

## 🛒 Storefront

**https://ramsandesh.gumroad.com**

## Publication files

- [ ] Correct edition/version selected.
- [ ] PDF opens and representative pages were visually reviewed.
- [ ] EPUB opens and navigation/TOC was checked.
- [ ] Six-volume files match the complete edition when included.
- [ ] Companion source-code ZIP matches the intended public code release when included.
- [ ] No obsolete X/Twitter profile URL appears in product metadata or bundled documentation.
- [ ] Canonical repository URL is `https://github.com/sanskarIN/dart-flutter-master`.

## Product page

- [ ] Title/subtitle are correct.
- [ ] Author is Ram Sandesh.
- [ ] Description accurately states included file formats and bundle contents.
- [ ] Cover/thumbnail matches the current edition.
- [ ] GitHub companion link is included.
- [ ] Support/contact information is current.
- [ ] Pricing/discount settings are intentional.

## Delivery test

- [ ] Download names are understandable.
- [ ] Archives extract successfully.
- [ ] Checksums/version notes are included when appropriate.
- [ ] A test purchase/download path has been verified when possible.
- [ ] Existing buyers receive the intended update behavior for revised files.

## GitHub coordination

- [ ] `CHANGELOG.md` reflects the release.
- [ ] `ERRATA.md` was reviewed.
- [ ] `docs/RELEASE_CHECKLIST.md` was completed for companion code.
- [ ] `bash scripts/verify-canonical-links.sh` passes.
- [ ] Git tag/release version is documented when a companion-code release is published.

After release, keep Gumroad and GitHub links mutually discoverable so buyers can find code/errata and GitHub readers can find the complete commercial editions.
