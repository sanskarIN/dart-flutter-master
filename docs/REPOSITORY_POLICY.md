# Repository Policy

This public repository is the stable technical companion for the book. It should contain material that readers can inspect, test, improve, and reuse under the stated code license.

## Include

- Companion source code
- Tests and fixtures that contain no sensitive data
- Exercises and educational solutions
- Master-project scaffolds
- Interview-practice code
- Documentation, errata, changelog, and release notes

## Do not include

- Paid complete book files or volume manuscripts
- Commercial cover/back-cover source artwork intended only for paid distribution
- Secrets, credentials, certificates, signing material, or private endpoints
- Proprietary third-party code/assets without redistribution rights
- User data or production database exports

## Stable metadata

Use `https://github.com/sanskarIN/dart-flutter-master` as the canonical project link. Avoid treating changeable social-profile URLs as permanent book metadata.
