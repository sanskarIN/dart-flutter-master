# Part 020 — Animations, Motion Systems and Custom Painting

[![Get the complete edition on Gumroad](../../assets/gumroad-badge.svg)](https://ramsandesh.gumroad.com)

This companion package matches Part 020 of the master manuscript and demonstrates explicit animation ownership, finite motion, easing, `AnimatedBuilder`, and a theme-aware `CustomPainter`.

The demo avoids an infinite repeating animation so automated widget tests can settle deterministically.

## Validate

```bash
flutter pub get
flutter test
flutter analyze
```

## Focus

- `AnimationController`
- Curved animation values
- `AnimatedBuilder`
- Motion-triggered UI state
- `CustomPaint` and `CustomPainter`
- Theme-aware painting
- Deterministic animation tests
