# Part 014 — Flutter Input, Forms, Validation and Submission Workflows

[![Get the complete edition on Gumroad](../../assets/gumroad-badge.svg)](https://ramsandesh.gumroad.com)

This companion package matches Part 014 of the master manuscript and demonstrates accessible input fields, pure validation helpers, form-state coordination, submission callbacks, busy-state protection, and testable success/error workflows.

## Validate

```bash
flutter pub get
flutter test
flutter analyze
```

`lib/main.dart` is the app entry point. Platform runner folders are intentionally excluded from this focused companion package.

## Focus

- `Form` and `GlobalKey<FormState>`
- `TextFormField`
- Pure reusable validators
- Input normalization
- Dependency-injected submission
- Busy-state protection
- Widget tests for invalid and valid submissions
