# Part 005 — Collections and Data Transformation

[![Get the complete edition on Gumroad](../../assets/gumroad-badge.svg)](https://ramsandesh.gumroad.com)

This package practices lists, sets, maps, ordering, grouping, and frequency analysis with pure functions.

## Run

```bash
dart pub get
dart run bin/main.dart
dart test
```

## Focus

- List/set/map behavior
- Deduplication and sorting
- Frequency maps
- Grouping values by a derived key
- Defensive normalization
