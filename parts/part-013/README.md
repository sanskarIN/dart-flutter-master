# Part 013 — Flutter Styling, Themes and Professional Design Systems

[![Get the complete edition on Gumroad](../../assets/gumroad-badge.svg)](https://ramsandesh.gumroad.com)

This companion package matches Part 013 of the master manuscript and demonstrates a small reusable design system built from semantic theme tokens rather than scattered widget-level styling.

## Validate

```bash
flutter pub get
flutter test
flutter analyze
```

`lib/main.dart` is the app entry point. Platform runner folders are intentionally excluded from this focused companion package.

## Focus

- `ThemeData` and `ColorScheme`
- Light and dark themes
- Semantic spacing/radius tokens
- Theme-aware reusable components
- Design-system consistency
- Widget tests for theme behavior
