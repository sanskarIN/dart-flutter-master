# Part 008 — Exceptions, Failures, Logging and Resilient Applications

[![Get the complete edition on Gumroad](../../assets/gumroad-badge.svg)](https://ramsandesh.gumroad.com)

This companion package matches Part 008 of the master manuscript and focuses on explicit validation failures, exception translation, recovery boundaries, and dependency-injected logging.

## Run

```bash
dart pub get
dart run bin/main.dart
dart test
```

## Focus

- Custom exception types
- Input validation and parsing
- Catching only at meaningful boundaries
- Fallback/recovery behavior
- Testable logging callbacks
