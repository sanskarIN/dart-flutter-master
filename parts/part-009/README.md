# Part 009 — Asynchronous Dart: Futures, Streams, Isolates and Responsive Flutter

[![Get the complete edition on Gumroad](../../assets/gumroad-badge.svg)](https://ramsandesh.gumroad.com)

This companion package matches Part 009 of the master manuscript and demonstrates deterministic Future/Stream composition, timeout recovery, and asynchronous transformation boundaries. Isolate-heavy work is intentionally left for larger compute examples later in the repository.

## Run

```bash
dart pub get
dart run bin/main.dart
dart test
```

## Focus

- `Future` and `async`/`await`
- `Stream` and `await for`
- Async transformation
- Timeout fallbacks
- Testable asynchronous APIs
