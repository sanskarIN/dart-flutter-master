# Exercises

Exercise assets should help readers practice without giving away the entire paid manuscript.

Recommended structure per exercise:

- objective
- starter files/data
- constraints
- acceptance criteria
- optional extension challenges
- validation/test command

Keep solution-specific implementation out of starter files. Reference the matching part number so readers can navigate between the book and repository.
