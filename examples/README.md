# Examples

This directory is for reusable, focused Dart/Flutter examples that are useful across multiple parts.

Every example should state:

- what it demonstrates
- required Dart/Flutter version or packages when relevant
- how to run it
- expected output/behavior
- important platform limitations
- tests or validation commands when practical

Prefer small examples over giant demo applications. Larger integrated work belongs in `master-projects/`.
