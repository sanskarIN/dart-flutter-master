# Code of Conduct

This project aims to maintain a respectful, constructive, and learning-focused community.

Be clear, patient, and specific when discussing code or documentation. Critique the contribution rather than the contributor. Avoid harassment, discrimination, threats, spam, doxxing, sexual content, or deliberately disruptive behavior.

Project maintainers may edit, hide, reject, or remove contributions and discussions that violate these expectations. Serious or repeated problems may result in participation restrictions.

For private conduct concerns, contact **sanskarin@outlook.in** with enough context for review. Do not post private personal information in public issues.
