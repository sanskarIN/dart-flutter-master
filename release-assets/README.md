# Release Assets

Paid book PDFs/EPUBs and commercial artwork are not committed to this public repository.

Use this directory only for release-oriented documentation or small public companion artifacts. Binary companion-code releases should normally be attached to a versioned GitHub Release with checksums.

Recommended release naming:

- `v1.0.0` — first complete companion-code release
- `v1.0.1` — corrections without new public API/features
- `v1.1.0` — backward-compatible new examples/features

Every release should reference `CHANGELOG.md`, review `ERRATA.md`, and state which Dart/Flutter versions and targets were validated.
