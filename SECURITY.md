# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, credentials, tokens, private user data, or a working attack against a deployed service in a public issue.

For a security-sensitive problem in companion code, contact **sanskarin@outlook.in** with:

- affected file/part and revision
- impact and prerequisites
- minimal reproduction information
- platforms/versions tested
- suggested mitigation if known

## Scope

The repository contains educational companion code. Example credentials and service adapters must remain non-production placeholders. Never commit real API keys, signing keys, passwords, certificates, payment secrets, or private endpoints.

Security guidance in the book and repository is educational and should be re-checked against current official platform documentation before production deployment.
