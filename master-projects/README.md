# Master Projects

This directory is for the production-minded projects from the final phase of the series.

Expected project documentation:

- product/domain scope
- architecture and dependency boundaries
- setup/run commands
- supported targets
- testing strategy
- security/privacy notes where relevant
- accessibility expectations
- failure/recovery behavior
- release checklist

Keep demo service adapters deterministic and credential-free unless a separate setup guide clearly explains safe local configuration.
